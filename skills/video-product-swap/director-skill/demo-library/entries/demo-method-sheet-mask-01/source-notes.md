# 面膜专用动作库

本库用于面膜类的动作选择和连续性检查，不是固定脚本。先确认面膜类型、首帧状态、原声时长及双手可用空间，再选择少数可完成的单元。不要把所有单元强行塞进一条视频。

## 1. 先分清类型和依据

| 已确认的产品类型 | 适用的操作核心 | 不可误用 |
| --- | --- | --- |
| 贴片式面膜 | 拆袋、取膜、展开、眼鼻口对位、贴合、局部抚平、展示贴合状态 | 取膏点涂、把膜布揉化或按摩吸收、凭空洗净 |
| 涂抹式面膜 | 真实取用、在适用部位形成正常覆盖层、展示当前涂层 | 生成片状孔位或膜布、默认揉到消失、套用贴片拆膜 |
| 水凝胶贴片、分区面膜等 | 按实际层片、上下片顺序、保护层及材质选择动作 | 凭空把整片分为上下片、增加背衬或耳挂、把凝胶片演成流动精华 |
| 需调配、撕拉或其他形态 | 仅采用用户或可靠说明确认的调配、等待、移除用法和现有条件 | 无依据添加碗、刷、水、干燥过程或撕拉步骤 |

不能只根据“补水面膜”“美白面膜”等功效名称判断使用形态。优先依据清楚的实物、用户说明和可靠使用说明；包装参考没有显示膜布时，不能默认它是白色、透明、厚棉布、生物纤维或带蓝色背衬。未知的关键层片/开口结构要说明，不虚构为确定动作。

膜布是有形实体，精华是可能附着其上的内容物，二者分开追踪。展示袋内精华或抹开精华不能替代用户要求的实际贴敷；不为了“质地展示”额外把整袋液体倒入手心。

## 2. 从首帧当前阶段接着做

| 首帧状态 | 可选起点 | 不应重演的动作 |
| --- | --- | --- |
| 持未拆封袋，尚未上脸 | 按真实包装开口拆袋，再取出同一片膜布 | 膜布未经拆取就瞬间贴脸 |
| 已开袋，膜布仍在袋内 | 从已有开口取膜 | 把袋口重置成封口重新撕 |
| 手持折叠膜布 | 寻找可辨认边缘、连续展开 | 重新生成一袋或直接变成平整上脸状态 |
| 已展开并手持膜布 | 孔位对齐、由实际接触区逐步贴合 | 折回去重新取膜 |
| 已有部分贴在脸上 | 贴合剩余边缘、局部抚平 | 重新取一片覆盖成双层 |
| 已全部贴好 | 调整确实可见的边缘、轻压贴合、展示当前状态 | 强行拆袋取膏；无依据立即揭掉 |
| 已到可移除阶段 | 只有用户/可靠上下文明确已完成实际敷用时，才连续揭膜 | 仅凭“首帧敷着面膜”就假定敷够时长 |

单片正常按实际一片编排；只有已知产品本来为上下分区或多片组合，才按对应片数处理。“正常一次用量”对贴片式体现为真实层片数量和使用方式，不写成米粒大小的膏点。

## 3. 贴片式可选动作单元

每个单元都要写清：起始状态→双手任务→路径与接触→膜布/配件变化→停留→下一状态。画面左右从实际首帧确定，不预设哪只手拆袋、哪只手贴脸。

### M1. 包装识别与开启

从现有握持姿态短暂展示同款袋装产品。需要拆袋时，一手稳住袋体，另一手在真实可见或已确认的易撕口/开口处施力，袋口沿受力路径打开。未知开口不能擅自编造拉链、拉环或剪刀。

若确实撕下独立袋角，必须交代袋角由哪手保留或沿什么有依据的路径放置。包装可以随操作降低、转向，不必全程正对镜头。

### M2. 从实际袋口取出

一手固定已打开的袋子，另一手拇食指伸向真实袋口，捏住折叠膜布的一处边缘，从袋内沿连续路径提起。湿润程度及颜色只在有依据时描述，不能用瀑布式流液夸张表现含量。

膜布从袋内逐渐露出，不在手中凭空生成。取出后的袋子仍在原手中，或通过明确交接/已确认承托面放置；不得自动消失、自动封口或变成另一袋。

### M3. 释放双手并展开

展开前先让双手确实可用。若一手仍持袋，只能选择可执行的交接、已有支撑位置或按素材允许的一手取膜阶段；不能边持续举着袋子边让同一双手完整展开并上脸。无承托条件且无法顺手交接时，指出具体瓶颈，缩小本条动作范围或建议经用户确认后调整首帧起点，不暗中改首帧。

两手分别捏住同一片膜布的两处可辨认边缘，沿实际折痕逐步分开。允许湿膜布自然垂落、折叠部分逐渐展开、局部轻皱；不能像弹窗一样瞬间伸展，也不能越展开越多出层片。眼鼻口孔位随展开逐步显露，保持同一片实体的连接关系，不凭空增孔或补孔。

### M4. 已有背衬或保护网的处理（条件单元）

仅在材料确认存在且说明需要取下时使用。按实际贴前/贴后移除顺序，一手稳住膜布边缘，另一手从明确的分离边揭开对应保护层；保护层不能被当成第二张敷用面膜。

取下层有连续去向，实际敷用层继续由手或脸部支撑。不擅自添加“蓝色背膜”“白色珍珠膜”，不假设每款都要去两层保护膜。

### M5. 孔位对齐与实际贴合

双手捏持不易撕裂的上部或两侧边缘，把已展开的同一片膜布移向脸部。先对齐眼部、鼻部和嘴部的真实开孔，再从明确的中央或上部接触区逐步向两颊、下巴贴合。孔位可由手轻调，不能随五官漂移变形来掩盖错位。

膜布只有接触皮肤后才贴附，未接触的边缘仍受双手与重力影响。鼻翼折片沿鼻侧贴合，鼻孔保持通畅；嘴部开孔不被拉成夸张的大洞，膜布不穿过嘴唇、眼睛或头发。无需为了包装持续露出而单手悬空完成整张复杂对位。

### M6. 局部抚平与轻压

从已经贴上的区域开始，用空闲指腹沿鼻侧、脸颊或下巴的一条短路线轻轻抚平，按真实可见的翘边/褶皱选局部，不每次重做整脸。膜布在接触受力时逐渐贴合，边缘、裁切口及原有纹理继续存在。

**抚平膜布不是推匀膏体。**不能把片材揉成液体、让膜布被皮肤吸收、手一划就消失；也不为了“手法丰富”反复用力摩擦或拉扯已经贴好的膜布。精华的轻微移动只作为实际接触下的附带变化，不另造涂膏流程。

### M7. 展示当下贴合状态与交流

双手离开主要观察区，让观众看清同一片面膜的孔位、边缘和贴合状况，可轻微转头后短暂停留。允许膜布随说话的面部运动出现合理局部活动，不让它浮离整张脸或大幅拉伸。

人物继续按完整原声说话，嘴部在实际孔位范围内运动，必要的局部遮挡可接受；不能为了强露完整嘴唇扩大开孔、缩小膜布或换脸。展示的是贴敷过程及当前外观，不宣称已经完成敷用疗程、精华全吸收或皮肤已经变白。

### M8. 揭膜与后续（条件单元）

只有当前片段起点已明确处于敷用结束阶段，或用户指定并提供可信的时间衔接条件时，才安排从真实边缘捏起、连续揭离。膜布沿接触区域逐步离开皮肤，仍为同一片，移除后继续在手中或有明确去向。

是否按摩残留、清洗或继续护肤，必须按该产品真实说明及现有场景条件选择。没有水源/用具不凭空洗脸；没有实际时长依据不在连续短片内演“贴上→敷完→揭下见效”。不新增时间字幕、跳切或变速来假装已经等待。

## 4. 涂抹式面膜的适配

只有确认是可涂抹形态才调用通用动作库中的取用与覆盖单元。内容物颜色、质地、取用工具与正常用量都依已知依据；不默认白色膏体、面膜刷、勺子或手指适用所有产品。

从容器真实取用，经接触转移到用户指定或产品适用的部位，逐步形成正常厚度和范围的覆盖层，避开产品说明要求避开的区域。涂层应保持可见，不默认像精油一样揉到透明或消失。仅在有依据时表现凝固、干燥、撕拉或洗净，且不压缩真实等待过程。结束可展示当前覆盖状态，不强求揭除或清洗。

## 5. 原声长度与执行难度

- 不预设固定秒数或每段固定动作。按实际原声、袋口、折叠结构、背衬、手位和空间估算时间，再写本次具体时间线。
- 先保留本条真正要表现的核心阶段，再删重复举袋、反复拉扯、二次取膜或无必要收尾包装展示；不要牺牲孔位对齐、实际贴合和看清状态的时间。
- 音频容不下从封袋到贴合的全流程时，明确哪个阶段不足。可提出“首帧已取出或已展开”的后续拍摄方案，但未经授权不编辑首帧、不宣称已完成被省略的拆取；当前稿标明未覆盖的使用阶段。
- 首帧已经贴好时，调整真实翘边、轻压和展示本身可以构成当前使用阶段，不必为证明使用再揭下来重贴；没有翘边时不故意生成大量翘边再修好。
- 敷用时长以可靠说明为准，未知不填写具体分钟数。口播短于完整敷用时长时，贴上即可在当下状态结束；完整原音频不拆分、不变速，除非用户另有要求。
- 不为腾出双手设计多轮复杂夹持接力。若现有首帧和支撑条件不能完成关键操作，具体说明限制，不能写出纸面上物品都在、真人却难以执行的手位。

## 6. 面膜专项验收

先按类型验收，再检查完整原声和人物产品一致性。贴片式重点看同一片膜布是否从真实位置连续到脸上、折叠层是否正确展开、孔位是否稳定、接触是否逐步发生、边缘是否仍在、手指是否真的推动了膜布局部，以及袋子/背衬/废弃物是否有去向。涂抹式重点看真实取用、转移和覆盖层。

允许材质合理形变、说话和必要遮挡；禁止穿透、多片增生、自动变色、把膜布涂化或瞬间美白。没有生成实测时只确认脚本与规则检查，不宣称视频效果已验证。
