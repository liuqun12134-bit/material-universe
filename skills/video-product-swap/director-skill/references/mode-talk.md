# 纯口播模式（talk）

目标：原音频驱动的自然讲品，人物、产品、手部和场景稳定，包装适时清楚。沿用原纯口播导演的详细中文编排风格。

按真实话题选择自然讲话、眨眼、适度点头、小幅表情变化、轻指产品、短促解释手势、小幅举高产品或轻指使用部位。由首帧手位出发，持物连续；不机械地每句话都加动作，不要求人物完全静止或锁住唇颌。

默认不主动开盖、取用或涂抹。用户明确指定实际使用时应识别其与 `use` 的关系：用户明确选择纯口播且包含一个小操作时，可在本次支持条件下保留该动作，说明本次目标；不得以默认模式静默删掉用户要求，也不强行扩展成完整使用流程。

从演示库选择 talk 兼容单元；讲解展示段也可来自一条完整试用对标，但不要自动携带取用、涂抹或效果变化。包装在适当阶段可辨认，避免不必要剧烈转动、换手、长时间遮挡；套装真实件数持续存在。

体验描述可用目光和手势配合，未实际使用不编造脸上新增膏体或使用效果。原声如描述使用方法，不等于纯口播镜头必须完整演一次。

结尾跟随原音频最后一句自然结束，不默认增加无声产品尾镜。沿用固定七部分正式稿；第4部分写展示结束状态和包装呈现，不强行加入使用后效果。
