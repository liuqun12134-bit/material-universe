# 固定交付格式

固定信息结构，不固定段数、动作数量或总时长。正常写稿及经验修订均使用本格式。

## 正式稿之外

简短说明模式、关键产品/首帧条件、音频读取情况、选择的演示与经验 ID（无则直说）。时间线可独立列表帮助审阅。原文转写仅在可靠读到或用户已提供时展示，注明来源。最多三条本次真实问题，无问题可省略。

## 一份独立完整的中文正式提示词

依次使用以下七个小节；所有具体内容在本次交付前填实，不能把空位、表格引用或库 ID 留给生成模型理解。不要把工具执行、知识库维护、查阅路径等内部说明放进正式提示词。

### 1. 素材映射与优先级

用实际 `@图1`、`@图2`、`@图3`、`@音频1` 等对应输入，说明首帧、身份、同款产品及原声的作用。映射未知时在正式稿外写“建议上传映射”，稿内仍统一使用该映射。图片标记不得有空格或使用旧前缀。无输入文件名、后缀、路径、网址和括号补充文件名。

### 2. 起始状态与演示目标

描述首帧持物、开合、脸上既有产品等真实起点，本片讲解/使用的目标以及已实测的音频长度。若无法核实长度，不能填写虚假精确秒数；关键缺失时整份标为待补充导演稿。默认手机质感、连续镜头。无需在此复述 API 参数。

### 3. 连续动作时间线

每段写时间区间（可靠性在稿外说明）、对应原声话题、眼神表情、手位、路径、实际接触、物品与内容物变化、结束状态、停留和下一段衔接。覆盖完整原声；按内容与可执行时长分段，不机械每五秒换姿势。台词可以不逐字写入动作段，不能加入新台词。

### 4. 过程变化与最终可见状态

use：具体写从接触到铺开/贴合/操作结果的渐进过程，以及同部位最终状态。产品质地与效果有依据，不编造透明度、白度、长期功效。talk：写产品展示和人物收尾状态，不添加未发生的使用效果。

### 5. 人物、产品与场景保持

写本次具体可见的身份造型、包装结构、材质、数量、光照与皮肤质感。允许动作必需的开合、手部换任务、朝向变化；同一产品的结构稳定不等于禁止正常操作。

### 6. 原声与口型

唯一声音来自完整原音频，保留词序、语速、停顿、音色，不加减重复、变速或重新配音。自然唇颌运动尽力同步，动作服从原声长度，不用改声音掩盖失配。音频结束自然停口，不默认增加无声尾镜。

### 7. 本次关键限制

少量针对性规则：身份和物体不漂移、不多手/穿模、不凭空转移内容物、不以曝光或换肤制造效果，无新增字幕、贴纸、BGM、音效或人声，保留包装和场景原有文字。禁止事项不能抵消第3部分所需动作。

## 最后扫描

全稿查找旧编号前缀、带空格的素材标记、文件路径及输出比例/像素/横竖屏/裁切补边语句。除非用户明确要求把输出规格写入稿中，否则删去规格与适配描述，保留动作相关构图。稿外的库来源和时间可靠性说明不混入正式提示词。
