# 边讲边用模式（use）

目标：观众能看见当前产品真实适用的操作、接触和结果，交流融入使用过程。开盖、取用、点涂、按压、贴合、合理放下与拿起是可选择的正常动作，无须逐个解禁。

先确认形态和用法，再从库检索，不能只凭“霜”“面膜”等名称猜结构或质地。取用量为真实用法与演示部位的正常一次使用量；有可靠说明依说明，未知时不编造克数，也不默认缩成米粒或微小点。

表情淡而自然，眉眼放松，保持自然说话运动；允许低头观察、短暂侧脸、局部遮挡和包装改变朝向。不能同时要求全程正脸、品牌始终朝镜头、一手始终举包装，而又安排双手操作。

## 连续状态

每段维护双手任务、容器位置/朝向/开合、盖及配件去向、内容物起点与转移、作用部位状态。盖子分离是同款商品的合理组成变化；不能用“始终只有一个物体”使盖消失。物品离开画面仍须有受支持的路径，不能把未知画外动作当作已完成事实。

内容物只有实际接触后才转移，指腹残留与皮肤新增相对应。变化逐步发生，不靠瞬间出现、消失、全脸重绘或曝光变化表达功效。用后外观要符合本品：某些产品留覆盖层，某些产品呈薄层或光泽，不能一概“吸收干净”。

演示目标先保留一次核心使用与看清状态，再删除重复取用、多部位、反复开合等。用户指定上脸不可默换成手背。首帧已有膏体或膜片时直接承接，不从拆封重演；过程不能压缩现实需要的等待时间。

## 结果验收

同一部位、同一光线曝光和皮肤纹理下，展示有依据的当前状态。素颜霜的即时润色需有产品或可核对演示依据，逐渐局部产生，不能全脸自动变白；长期淡斑、抗老等不作为短片即时结果。

只有包装展示、指脸或假接触时，不能判为完成使用目标。遇到结构、时间、空间不足，明确未完成项与可选调整。诊断修订保留用户满意部分，不能通过删掉所有使用动作解决问题。
