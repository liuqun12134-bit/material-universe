# 通用方法辅助（非实测经验）

这里保留原导演规则中的可复用方法，只在缺合适案例或需要补足衔接时读取。具体品类演示记录从索引检索；不能把本文件当作用户视频观察或已验证成功经验。

| 已确认结构 | 操作要点 | 适用边界 |
| --- | --- | --- |
| 有盖罐 | 双手开启，盖有去向，露出内容物再取用 | 未知旋开/拔开方式时不编造；开盖首帧不重复开 |
| 软管 | 按真实盖体开合，出口对准接收位置，受力处变形并连续出料 | 不让内容物凭空悬浮，不猜颜色和用量 |
| 泵瓶 | 确认泵头状态和出口，接收手位在出口下再按压 | 不把未解锁结构写成可直接出料 |
| 滴管 | 提起、滴落与接收路径连续 | 需有结构、流动性质和手部空间依据 |
| 可涂膏液 | 正常一次用量，接触后转移，从已有膏点逐渐推开 | 遮盖、成膜、清洁、留敷等用法不同，不默认都按摩吸收 |
| 可贴柔性片材 | 从首帧阶段承接，释放双手，展开、定位、接触、局部抚平 | 同一片实体与开孔持续，已有背衬才安排去除；不套用膏体揉化 |
| 工具/家居用品 | 结构展示、一次真实操作、可见结果停留 | 道具、污渍、安装条件需有依据 |

效果从产品依据确定：均匀覆盖不等于完全透明；即时润色不等于改变真实肤色；有光泽不证明吸收或不黏；贴合不代表等待完整疗程；生成的效果不是产品功效证据。无法确认的关键属性应询问或交付待补充部分。
