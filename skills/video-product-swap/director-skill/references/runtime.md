# 跨环境运行与迁移

本 skill 是规则与资料包，不内置生图、视频生成、ASR 服务或凭据。目标 agent 能读文件即可读规则与文字库；视觉分析依赖其看图/看视频能力，音频内容依赖可靠听取或转写能力；持久更新需文件写权限。

用可用的本地媒体工具读取元信息与抽帧，例如 ffprobe/ffmpeg；这些工具若不存在，使用宿主实际提供的媒体能力。不要声称一个固定工具在所有环境中存在。未经本次授权不把用户原始媒体上传到第三方服务来补齐能力。

关键帧保留原始画面与时间来源，可抽取必要帧或原样另存，不用生图重绘证据。观察整个视频及关键交互附近的连续画面，静帧不足以判断动作全程、音画同步、物品画外去向。无法访问视频时不能当作已完成视频入库，可基于用户说明交付待完善记录。

所有相对路径以所在记录/文档为基准，库内资产须实际位于对应记录目录；不要保存临时链接代替迁移资产。原视频可不随包，但 provenance 明确说明；视频不在包内时，文字和关键帧可迁移，重查原视频能力不随包迁移。

维护一份可写主目录。迁移复制整个 skills/seedance25-commerce-director 目录；不只复制 SKILL.md。agents/openai.yaml 是 Codex 界面元数据，其他 agent 可按其入口规则加载 SKILL.md，正文和库无需绑定该界面。

更新代码/规则前备份已有安装。保留本地新增的 demo-library 与 experience-library 记录和资产；同 ID 不同内容不得静默覆盖，要比较并保留历史/解决冲突，再重建索引。重新安装不代表同步了另一台电脑的数据。只修改安装缓存可能被升级覆盖，应使用稳定可写的个人技能目录或维护主目录。

图文库默认按需读；首次索引由脚本构建。Python 3.10+ 可运行 scripts/library.py（只用标准库）；无 Python 时可以直接维护同一 JSON 文件和索引，明确未执行脚本校验。GitHub 同步是独立动作，需要明确授权，凭据不得写进技能文件。

自优化 v1.1：开关和自动新增经验另存于用户级 `.local/share/skill-learning/`（可配置 SKILL_LEARNING_HOME），不在安装目录。迁移需另行复制该目录；升级保留它。原手动演示/详细经验库仍按上述备份合并流程，不要因安装新版覆盖。GitHub 仅同步本次明确选择的规则/包，外置个人数据默认不上传。
