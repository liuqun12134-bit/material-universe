# 素材万象 1.9.3

日常使用推荐「素材万象安装程序.exe」；临时使用可运行「素材万象.exe」。升级前先退出旧程序，旧版已备份到历史版本目录。

新版默认打开图音生视频。Fish Audio 和 Kaiyun GPT-6.1 Sol 在设置中配置。智能提示词是可选功能，必须手动选导演模式；Fish 自动转写音频，Kaiyun GPT-6.1 Sol 编排后填入提示词框，不会自动生成视频。

视频换品、换口型、画质修复和 Omni 视频编辑不再提供新建入口，旧素材、成片及任务记录保留。使用记录可刷新、查看详情并恢复已提交的任务。

声音合成现按 Fish 网页版范围提供语速 0.7–1.3 倍、音量 −5～+5 dB，默认 1 倍、0 dB。设置随任务提交给 Fish，本地保存不再减速或调整音量。恢复默认即可还原这两个值。旧音频保留；复用旧配置会提示换算并重新预估。

已通过免费草稿验证参数写入，以及离线声音流程和音频保存一致性测试。未调用真实付费生成，实际音质仍待正常使用验证。

智能提示词固定使用 kaiyun 的 `gpt-6.1-sol`，素材核对与写稿共用设置中 KaiyunCode 的 API 地址和 Key，显式保留 medium 思考档位。Fish 转写与视频生成流程不变。
