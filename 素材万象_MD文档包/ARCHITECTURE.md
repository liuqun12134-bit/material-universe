# 2026-09-21 桌面任务与素材改造（1.4.0）

用户已批准三个生成入口、使用记录、素材库及最多十并发，本节优先于下方旧版界面说明。

- `desktop_tasks.py`：SQLite 持久化任务及素材索引；受控线程队列，三个功能共享 1–10 个执行槽；每条任务配置及凭据独立，凭据只在内存中。
- `desktop_pages.py`：使用记录与素材库界面。记录在分析/上传之前建立；逐阶段进度写入本地，无虚构百分比。生成入口不承担异步结果展示。
- `video_gui.py`：选择素材及参数后创建任务。调用共用 Skill 函数，无全局单任务锁定；“重新分析”和“已有提示词”分离。
- `ProductSwapWorkflow.generate` 的桌面可选参数为 `prompt_override`、`prepared_callback`、`extra_images`；Agent CLI 原有契约不变。复用模式跳过分析并原样传递提示词。
- `ModelRunner` 的可选进度回调与 TaskRecord 更新回调将服务商状态、ID 和下载阶段汇报给桌面；Skill 不依赖桌面模块。
- 素材按 SHA-256 去重保存副本，删除引用中的素材被阻止。记录删除留存墓碑，避免旧 JSON 在启动时被重新导入。
- 重启只自动恢复已受理任务的查询；本地尚未提交任务需手动启动，提交结果不明确禁止自动重提。只有一个桌面进程可以调度同一数据目录。
- 自动化验收：`tests/test_desktop_tasks.py` 验证并发/隔离/恢复/素材生命周期；`packaging/test_desktop_workflow.py` 用真实 Tk、媒体探测及 SQLite 连续操作三个入口，替换付费服务边界，禁止网络调用。

# 素材万象当前架构

更新：2026-09-05。此文件只描述当前实现；历史设计以版本记录和 DECISIONS.md 为参考。

```text
桌面界面 / Agent
        ↓
视频生成 Skill
├─ 通用模式：用户提示词
└─ 换品模式：内部分析视频 → 固定提示词
        ↓
同一套视频模型适配器
        ↓
提交一次 → 保存任务 ID → 查询 → 下载
```

## 当前在用

- `generate_video.py`：Agent/命令行入口，解析参数，返回 JSON。
- `product_swap.py`：桌面和 Agent 唯一的换品流程，先本地检查，再分析、拼提示词、生成。
- `prompt_engine.py`：抽帧、DeepSeek 位置识别、用户尺寸关系整理、固定模板；不读取密钥文件。
- `model_runner`：模型登记、参数校验、服务配置和各模型适配器；通用模式与换品模式共用。
- `task_state.py`：输出旁的 JSON 任务记录和本地文件锁；支持查询/下载恢复，不自动重新提交。
- `video_gui.py`：界面、媒体预览、配置快照和结果展示，直接调用业务函数。源码与 EXE 使用同一路径，不再模拟 CLI 或修改进程的工作目录/环境。

单独的提示词 Skill 保留为薄入口，复用视频 Skill 内部分析模块，仍使用自己的 `.env`。视频 Skill 不依赖提示词 Skill。

## 两个入口的规格

- Agent 换品预设：原视频最长 15 秒，时长向上取整且至少 2 秒，标准比例跟随原视频，非标准比例 9:16，480p；固定 DeepSeek 与 fal Wan3（`alibaba/wan-3.0/reference-to-video`）。
- 桌面：保留用户选择的视频服务、分析模型、秒数、比例和分辨率；这些值显式传入同一流程，视频限制由所选适配器检查。桌面原有时长取整方式保留。
- 通用模式：用户明确提示词、模型、参考和输出规格，不分析画面。

## 密钥

独立视频 Skill 只读取自身根目录 `.env`。不读工作目录或同级 Skill，不修改 `os.environ`。桌面以字典快照传入应用自己的配置。命令行 `host-app` 显式使用环境快照。不同服务的 Key 独立，不猜线路。

fal 全程使用 HTTPS JSON 接口：本地素材先经 `rest.alpha.fal.ai/storage/upload/initiate` 申请签名地址上传取得 URL，再向 `queue.fal.run/{模型ID}` 提交；按 request_id 轮询 status、取 response。查询与下载地址不带 API Key。

## 任务恢复

在正式提交前写入 submitting 记录，拿到任务 ID 后立即落盘。网络失败保存 interrupted，服务端失败保存 failed，下载失败保存 generated 并保留 URL。`--resume` 只查询或下载；没有任务 ID 的不明确提交需先到服务商核实。输出文件存在时不覆盖；同一记录禁止并发执行。

## 分发

Agent ZIP 直接按允许文件列表打包当前视频 Skill，包含内部分析模块。桌面安装版和便携版使用同一源码模块；不再复制同级提示词脚本、不按标题改写 SKILL.md。发布必须对应准确的源码提交。密钥、任务记录、用户素材不进入发布包。

## 已开发待定与未来

产品图预处理保留为独立工具，未自动接入个人换品流程。声音克隆、换口型、账号和商业平台不在本次整理范围。现阶段以真实成片可用率、成本和节省时间验证价值。
