# AI 美工与 AI 导演（开发版）

创作页的两个辅助入口分别命名为「AI 美工」与「AI 导演」，继续单次整理提示词。设置中可分别打开学习与规则管理，查看「待确认、学习资料、工作规则、变更记录」。图片结果旁有「结果反馈」，已完成的图片/图音视频任务详情也可提交反馈。

图音生视频和 AI 生图在确认费用、任务成功加入本地队列后，自动清空本页素材、提示词、助手补充要求、生成稿及撤销记录，并恢复生成参数默认值。图音页同时清空音频时长、停止试听并恢复未选导演模式；AI 生图保留右侧结果和历史记录。取消、预估失败或本地提交尚未确认时保留草稿，核对到原任务后再重置。素材文件、账号、输出目录及已确认的学习规则保留；可从使用记录明确复用旧任务。

自进化默认关闭、两个助手独立设置。关闭时反馈只保存在个人库；开启后仅对明确提交的反馈调用 Kaiyun GPT-6.1 Sol 整理建议，不因生成完成、下载或未反馈而自动学习。主动学习也可在关闭时使用。新建议和编辑后的规则先进入待确认，确认并启用后才参与下一次助手提示词；已有规则的待确认修改不替换旧生效内容。批准采用不等于成片效果已经验证。可停用、查看前后变更、将旧版本恢复为待确认。

学习资料支持一次最多 8 张图片；AI 导演还支持一次一段 3 分钟内、512 MB 内的本地视频。视频以时序抽帧分析动作，不分析音频，不声称完整动态或口型已验证。保存资料先在本地准备证据，点击「整理建议」才发送画面与要求并计费；相同资料和要求不重复创建，已整理的资料不会再次付费分析。AI 导演设置也能查看已有内置/个人 Skill 演示库。

新资料、建议、确认版本与历史保存在个人 Skill 附属库的 `assistant-knowledge` 中，与程序和账号分离，并纳入现有库导入导出与升级备份。两个助手只读取所属范围已确认且启用的内容；导演另按纯口播/边讲边用过滤。本次明确要求优先，案例按适用条件选用；手写提示词不会被后台自动改写。

反馈保存时核对任务中的素材校验记录。文件被替换、损坏或读取期间发生变化时保留文字反馈，并标明缺失的证据；旧记录没有校验信息时会明确提示只能作为当前文件参考。

# AI 生图（开发版）

侧栏「AI 生图」提供一个自动保存的表单：直接写提示词进行文生图，或从本地、素材库一次选择多张参考图，按 `@图1`、`@图2` 等编号引用。不再使用聊天、项目和版本分支；最近结果平铺展示，已有图片与任务保留。

默认 GPT Image 2.5 Sunburst、1K、中等精度、9:16，每次只生成一张。可选择模型、比例、分辨率和精度；选项随模型真实能力变化。内置八个 Fish 生图模型的规格快照，连接后刷新目录与规格，正式报价再次核对实时能力。不支持的参数显示模型默认，切换模型时保留提示词和全部参考，超过数量上限需调整后生成。「恢复默认」按钮只重置生成设置；确认提交成功后则自动重置整个创作表单。

参考图位于提示词上方。「AI 美工」展开后只需描述想要的效果，AI 自动结合参考图理解需要改变、保留的内容，无需选择母图、角色或修改方向；没有参考时也可整理文生图提示词。辅助使用现有 Kaiyun GPT-6.1 Sol，结果可编辑、撤销和查看，迟到回复不覆盖新输入。旧辅助草稿转换为可见的文字要求。普通生图直接调用 Fish，不要求先使用辅助。

预估时上传或复用参考，显示 Fish 实际积分报价，确认后提交一次。重复点击不重复创建任务；响应不明不自动重提，有编号只查询，有图片地址只下载。图片自动进入素材库，可放大对比、另存、作为新参考、复用参数或回填图音生视频首帧。预览提供缩小、放大和「适应窗口」，滚轮缩放、拖动查看；点击最近结果会重置到适合窗口的大小。图音页辅助入口名为「AI 导演」。

切换图片保留最近结果的缩略图控件，后台读取、缩放并缓存图片；快速连点仅显示最后选择的结果。左右区域与预览尺寸随窗口调整，不随横竖图或图片大小改变。

参考删除后会同步更新后续编号，原引用标成「【参考图已移除】」，修正后才能生成。当前表单和任务保存在本机数据库；旧聊天数据留档但不再驱动界面。现有库导出不搬运表单与使用记录。

从项目根目录「启动素材万象.cmd」运行源码版即可使用；既有安装程序未因此自动更新。开发验收使用隔离素材与模拟服务，不上传真实参考、不执行付费生图；真实生成效果仍以实际使用为准。

# 素材万象

素材万象是一套面向电商产品素材的本地 AI 工具，当前重点是视频换品：参考视频位置分析、固定提示词生成，以及 fal 或阿里官方百炼视频生成。

## 简化后的调用关系

桌面或 Agent → 视频 Skill → 通用提示词 / 内部换品分析 → 所选服务商的模型适配器 → 保存任务 ID、查询、下载。

桌面和 Agent 复用同一换品流程；视频 Skill 已自带提示词引擎。独立调用只读自己的 `.env`，桌面显式传入自己的配置。断网或下载失败后，命令行使用 `--resume <输出文件>.video-task.json`，桌面点击“继续已有任务”；不会重新提交生成。

## 当前组件

- `video-product-swap`：通用模式自选提示词、参考文件、模型及输出参数；视频换品模式输入视频、产品图和尺寸关系，自动用 DeepSeek 分析并调用 Wan3。桌面换品支持 fal 和阿里官方百炼 Wan3 标准版 / Prime，两条线路使用独立适配器及凭据；Sync3 换口型和 FlashVSR 画质修复仍使用 fal。
- `ai-video-swap-prompt-generator`：从参考视频抽帧识别产品位置，整理用户提供的尺寸关系，并拼装固定提示词（视频 Skill 已内置同一引擎，本 Skill 保留为独立入口）。
- `素材万象` 桌面界面：统一选择素材、配置输出规格并管理宿主应用自己的 API Key。换品和画布视频草稿都可以选择服务商；原有 fal 配置保留，切换不改变已提交任务的线路。

## 当前版本（1.8.0）

新增独立「图音生视频」模块，固定 Fish Audio MCP / Seedance 2.5。必填首帧构图参考图、人物多视角图、产品多视角图各一张，MP3 / PCM WAV 音频一条及提示词。默认 9:16、480p，秒数按音频时长向上取整且至少 4 秒，最长 30 秒，用户可调长但不能短于完整音频。音频实际时长必须在 1.8–30 秒以内；检查真实封装、编码与完整解码，拒绝改后缀文件。图片检查静态格式、解码、尺寸和大小。

在模块内点击「连接 / 切换账户」，浏览器 OAuth 登录 Fish 并选择工作区；授权独立使用 Windows 加密存储，不读取聊天应用的授权。提交先本地检查和上传到 Fish 工作区，再显示实时积分报价，确认后进入已有共享队列（使用记录中 1–10 并发）。素材和报价冻结，变化后须重新估价；每条任务只提交一次，响应丢失无编号时要求核实，有编号时仅恢复查询/下载。多参考模式传三张 ref 与一条 audioRef，首帧图用作开场构图参考，不能保证逐像素锁首帧。

源码与发行包使用同一模块；离线验证不提交真实付费生成，首次真实登录、生成响应和成片效果仍需账号实测。

本次离线验证不调用收费生成，不上传实际用户素材；真实服务账号权限、生成效果仍以实际调用为准。

素材库按“筛选 → 选择素材 → 使用”排列。顶部集中分组、类型、名称搜索及独立的导入入口；底部显示选择数量、用途与一个使用按钮，预览和移动分组为次操作，重命名及删除放入“更多”。没有选择或类型、数量不符时不可使用；产品图支持 1–10 张，其余用途每次选择 1 个对应的视频或音频。从功能页进入素材库会保留用途和分组，清空旧搜索及选择，不会自动更换用途。导入进度及结果独立显示，定时刷新不会覆盖。

根据用户决定移除试用版新增的「AI视频换产品和音频」模块，撤回分段确认与自动合成入口。创作画布、视频换品、Sync3 换口型及任务恢复继续按现有方式使用。已有成片、素材和任务记录保留，不删除本地历史数据。

画布播放器隐藏了菜单中失效的内置下载项，生成结果请使用卡片下方“下载”按钮。在嵌入窗口里使用原生保存对话框另存本地成片，取消保存不影响原文件；在普通浏览器中使用附件下载。播放器的倍速、全屏和画中画功能按原浏览器能力保留。

阿里官方 Wan3 使用百炼原生异步接口及 OSS 临时上传，不经过 fal。先在设置填写“阿里官方（百炼）”的 API Key，再在换品页面或画布视频草稿选择服务商与标准版 / Prime。默认北京服务地址，也可填官方地域或业务空间地址；API Key 与地域需一致。旧任务继续使用提交时的服务商、型号和地址。

画布提示词、尺寸关系和备注支持输入法组合保护：正在选字的拼音保留在输入框，选字完成后再进入画布历史与自动保存；组合期间不触发画布快捷键。新生成任务使用“设置”中的成片保存目录，修改目录只影响新任务，恢复已有任务仍使用原来的输出路径。

素材库现在可新建、重命名和删除自定义分组。先选分组，再按视频、图片、音频和名称筛选；可多选素材批量移动到任意分组或未分组。删除分组只让组内素材回到未分组，不删除文件。旧素材默认归入未分组；重复导入相同内容会保留原素材及其分组，如需调整可批量移动。

在主窗口选择分组后，新素材会导入当前组；选“全部分组”时，新素材进入未分组。创作画布左侧素材库也支持相同筛选和导入目标，分组管理仍在主窗口。筛选只影响素材列表，画布上已有卡片、任务引用和历史配置保持可用。首次升级旧素材库时会自动生成一份 SQLite 备份。

视频换品、换口型和画质修复各保留一个生成按钮。任务进入本地队列后弹框提示到“使用记录”查看进度，确认后可继续按当前素材和参数生成下一条，后台任务继续排队或并发执行。双击与重复提交仍由请求 ID 去重；提交响应丢失时重试核对原任务。使用记录统一从侧栏查看，实际并发数由使用记录中的并发设置决定。

主窗口的 X 会关闭窗口并驻留右下角系统托盘，已提交任务继续执行。点击托盘图标或右键选择“打开素材万象”可恢复窗口；彻底退出请在托盘菜单选择“退出软件”。托盘建立失败时窗口保持可见，可以继续使用、重试或明确退出。未完成任务按原有规则持久化和恢复。

## 创作画布

创作画布面向通用 AI 创作。新任务提供 fal Wan3 文生视频 / 参考生视频、阿里官方 Wan3 标准版 / Prime 以及 Sync3 对口型。阿里官方支持无参考文本生成及图片、视频、音频参考；对口型必须恰好使用一个视频和一个音频，不需要提示词。文生图已退出新建目录，历史图片结果和原任务恢复仍保留。原有业务功能模块继续可用。

在主窗口侧栏点击“创作画布”，会在主窗口内显示无限画布。可新建、重命名和切换画布，缩放、移动视角，导入图片、音频和视频，或从素材库将素材放入画布并连线。导入素材会保存在本地素材库，按文件内容去重。

把素材卡连接到未提交的通用任务，实线会将素材绑定为实际输入；卡片列出已采用的文件，勾选参考与连线保持同步。断开最后一条同素材输入线会移除该参考。不兼容的素材或超限输入会被拒绝。旧版仅记录来源的线显示为虚线，不参与生成。提示词无需插入本地文件名，文件作为独立参考上传。

在任务卡内配置模型、提示词、参考素材和参数，点击开始后可直接在卡片上查看真实任务状态、执行阶段以及已下载的结果。结果可加入素材库并作为参考继续创作。连线、复用配置均不会自动提交收费生成；已提交卡片的配置及输入绑定冻结，删除整张任务卡不会删除或停止后台任务。旧版换品、换口型和修复任务仍可查看及恢复。

AI 视频换品新增默认关闭的“去字幕模式”。开启时，Wan3 换品最终提示词前加上“先把参考视频中的字幕去掉，再”；桌面、画布换品卡片和 Skill 命令行共用此规则。历史复用保留原始提示词，关闭开关后不会残留系统前缀；成片字幕是否去除仍需人工查看。

fal 视频换品的“提示词扩写”和“思考模式”默认开启，桌面与画布都可分别关闭，对应 fal 的 `enable_prompt_expansion` 和 `enable_thinking`。阿里官方将扩写映射为 `prompt_extend`，不提供 fal 的思考模式选项。“已有提示词”只在选择复用时显示；产品参考图是换品目标产品的必需输入，继续保留。字幕是否真正去除仍需查看成片，本版未做付费效果对比。

换品位置分析同时发送 12 帧时间序列图和 3 张原尺寸代表画面。手指夹捏、细长透明或部分遮挡的产品属于“人物手中”。分析服务漏返或误返位置字段时会给出明确错误，并在提交视频生成前停止。视觉分析费用以服务商实际用量为准；未取得服务凭据时，离线测试只能验证抽帧和请求结构，不能证明模型实际识别结果。

参数依据：[fal Wan3 文生视频](https://fal.ai/models/alibaba/wan-3.0/text-to-video)、[fal Wan3 参考生视频](https://fal.ai/models/alibaba/wan-3.0/reference-to-video)、[阿里官方 Wan3 API](https://help.aliyun.com/zh/model-studio/wan3-video-generation-api-reference)。

画布与主窗口共用现有任务队列，默认最多 3 个任务并行，可在使用记录中设置为 1–10。关闭画布但保持素材万象主程序运行时，已提交任务继续执行。画布内容和任务记录保存在本地 SQLite 数据库中；退出整个程序后的未完成任务仍按现有任务恢复规则处理，不会自动重提付费生成。

Windows 画布窗口需要 Microsoft Edge WebView2 Runtime。画布与任务队列使用离线模拟验证；没有进行真实付费生成或画质验收。

## 使用

安装 Python 依赖后，双击根目录的 `启动素材万象.cmd`，或进入 `skills/video-product-swap` 运行：

```powershell
python -m pip install -r requirements.txt
python scripts/generate_video.py --list-models
```

正式生成前可以使用 `--dry-run` 检查模型线路、输入、上传字段和请求结构。检查模式不会上传文件或提交付费任务。

## Windows 安装版（推荐）

运行 `packaging/build_installer.ps1` 可以在 `发行版` 文件夹生成 `素材万象安装程序.exe`。安装后，素材万象会出现在 Windows 开始菜单和“已安装的应用”中，并带有标准卸载程序；安装时也可以选择创建桌面快捷方式。

安装版使用免重复解压的程序目录，默认安装到当前用户的 `%LOCALAPPDATA%\Programs\MaterialUniverse`。工作区位于 `%USERPROFILE%\Documents\素材万象`，API Key、设置和日志位于 `%LOCALAPPDATA%\MaterialUniverse`。卸载程序不会删除工作区和已经生成的视频。

## 单文件便携版

发行目录外层只保留当前便携版、当前安装程序和使用说明。旧程序按“便携版 / 安装版”归入 `发行版/历史版本`；版本信息、验收记录和 Agent 技能包归入 `发行版/维护资料`。卡顿诊断和便携版回退入口位于项目根目录的 `维护工具` 文件夹。

运行 `packaging/build_release.ps1` 可以在 `发行版` 文件夹生成单文件 `素材万象.exe`。成品已包含 Python、模型适配器、界面资源以及 FFmpeg、FFprobe、FFplay，目标 Windows 电脑不需要安装或配置这些组件。

单文件版适合临时复制使用；日常使用优先选择安装版，避免每次启动时重复释放内置运行文件。

使用者首次打开后只需在“设置”中填写自己的提示词分析和视频服务 API Key。真实 Key 不参与打包，也不会提交到仓库。

## 凭据安全

仓库只提供 `.env.example`，不包含任何真实 API Key。请在本机配置自己的凭据，不要把 `.env`、日志、生成视频或加密凭据文件提交到 Git。

桌面应用的 API Key 与各个 Skill 自己的 `.env` 相互隔离；宿主应用未配置 Key 时会明确停止，不会静默读取 Skill 的 Key。
